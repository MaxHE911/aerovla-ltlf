## 题目（候选）

1. *Logic from Demonstration: 训练无关的时序逻辑层能否为 UAV 视觉语言导航带来可验证的任务进度？*
2. *From Boolean to Quantitative: 面向 UAV VLN 的 LTLf/STL 双层任务逻辑接口*

## 1. 问题与动机

UAV 视觉语言导航（VLN）的目标指令越来越长（"先经过 A，再到 B，最后落在 C"），
而当前 SOTA（AerialVLA/AeroVLA 一类）仍是**单目标、单提示词**策略：
- 一句话塞进模型，模型自己决定何时算"到了"；
- 评测只有终点成功率（SR），**无法回答"过程对不对"**；
- 指令里的**顺序**与**时间**信息完全没有被使用。

## 2. 现有工作与不足（三篇参考）

| 工作 | 做了什么 | 缺什么 |
|---|---|---|
| Logic-VLA | STL 作为**条件输入**训进策略（两阶段：条件 SFT + IPO） | STL 公式是**模板采样**，与自然语言/示范无关；需要重训 |
| STL Translation & Repair | LLM 翻译 NL→STL + 求解器不可行时修复 | 依赖 **MILP 轨迹合成**；我们这类端到端策略没有约束集 |
| STeP | STL 鲁棒度作为 **10 Hz MPC** 的目标项 | 依赖**动力学模型与优化器**；且是机械臂而非 UAV |
| RefineFly | 同底座 RL 后训练（PPO + 失败记忆） | 只有终点奖励，**无任务结构**；代码未开源（权重匿名开放） |

**共同空白**：没有人回答"**逻辑从哪来**"。三篇工作的逻辑要么是模板、要么靠 LLM 翻译、要么靠人工写。

## 3. 我们的方法：三层递进（外挂 → 定量 → 内化）

### 3.1 第一层：从示范里"挖"规范（M0，训练无关）
- 用 `map_spawnarea_info.json` 的地标几何 + 专家轨迹，**自动**得到"经过哪些地标、什么顺序"；
- 编译成 LTLf 公式 → 残差自动机 → **阶段分解** → 逐阶段改写提示词；
- 在线用 12 m 球邻域做事件监视，维护残差。

**已确证的收益（N=21，MCM RT 组）**：阶段完成率 **.683 vs .333**；按顺序经过地标（chain 满足率）**.625 vs .000**。
**未确证**：终点成功率 SR（.333 vs .333，配对 McNemar p=1.00）。

### 3.2 第二层：从布尔到定量（STL，训练无关）
同一份任务用**采样时刻 STL** 再写一遍（时间单位 = 宏步，因为动作执行时长不固定），得到：
- **鲁棒度 ρ**（单位是米）："离违反还有多远"；
- **截止期**（来自专家到达时刻，弧长重采样换算）；
- **安全包络**（来自专家飞行高度分位数）。

**已确证**：
- 实现与 LTLf 判据在 8 组上百条 episode 上**完全一致**（1.000），即不是换了判据；
- 三个机制都可审计（shield 触发次数、改动量、截止期提示次数全部落盘）。

**已否证的假设（诚实记录）**：
- 把安全包络下界从 1.72 m 抬到 6 m **没有**改善 SR（.333→.167），
  因为"裁剪到边界"等价于"贴着地板飞"（中位高度 8.76→6.09 m）；
- 更深一层：**"低空↔碰撞"是相关而非因果**。

### 3.3 第三层：把逻辑训进模型（后训练）
- **Stage A（逻辑条件 SFT）**：同一批专家帧、同一批动作标签，只把指令**改写成分阶段提示** → **零新标注**；
  已生成 13,715 条，方向分桶与 baseline 逐条一致（3000 条 0 误差）。
- **Stage B（失败对齐）**：从闭环失败造偏好对做 DPO（我们的动作是离散 token，log-prob 可算，比 Logic-VLA 的 flow-matching 代理更干净）。

**已确证**：管线跑通（loss 6.20→0.82，可训参数 2.98%）。
**已发现的坑**：**125 步就把策略训成常量输出**（139 步只有 2 种动作）→ loss 不是策略质量的代理。

## 5. 预期贡献（现在的写法）

1. **方法**：一个**从示范自动构建**任务规范、且**训练无关**即可工作的逻辑层（区别于模板/翻译器）；
2. **形式化**：给出 LTLf（顺序）与采样时刻 STL（裕度+截止期）的双层接口，并证明二者语义一致；
3. **实证**：在这套基准上量化了"逻辑层能买到什么"——**买得到过程合规，买不到终点成功率**；
   并给出为什么（碰撞主导）与下一步（障碍谓词/后训练）；
4. **可复现**：完整代码/脚本/数据管线 + 一把被外部权重校准过的"尺子"（RefineFly 复现 +8.3 pp）。

## 6. 风险（写进摘要之前必须解决）

1. SR 没有提升——摘要要么把"过程指标"立为主贡献，要么等障碍谓词实验；
2. 后训练塌缩——必须先证明"能训不塌"；
3. 样本量小（12–21 条/臂）+ 仿真不可复现——需要多 reset 重复；
4. 只有 ModernCityMap 一张图有完整对照。
